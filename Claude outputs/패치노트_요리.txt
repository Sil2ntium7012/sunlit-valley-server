# :cooking:  새 상점 「요리」 추가
- 요리 재료 이전
> 시장에 있던 요리 재료들이 전부 요리 상점으로 옮겨졌습니다
> 쌀 128원 / 사탕수수 96원 / 알프스 소금 8개 64원 / 설탕 8원
> 유리병 8개 2원 / 병 8개 8원 / 와인병 8개 1원 / 맥주잔 8개 2원 / 그릇 8개 2원
> 건조기 20,480원 / 요리 안내서 32,768원 + 무지갯빛 파편 1개
> 계절·해금 조건이 사라져 언제든 구매할 수 있습니다

- 요리 도구 신규 판매
> 메이슨 병 4개 16원 / 도마 64원 / 철 식칼 128원 / 빵 칼 128원
> 발효용 병 128원 / 바구니 128원 / 스킬렛 192원
> 요리 냄비 256원 / 스토브 256원 / 주방 싱크대 256원
> 작은 요리 냄비 512원 / 요리 팬 512원 / 달인의 요리 냄비 1,024원
> 양조 스테이션 2,048원

# :seedling:  열매 ↔ 묘목 교환
- 농부(시장)
> 모든 과일나무 48종의 열매 8개 → 해당 묘목 1개 교환 추가
> 기존 돈으로 사던 묘목도 그대로 남아 있습니다
